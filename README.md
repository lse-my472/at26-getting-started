# Getting started with MY472

Welcome to MY472! We use the course GitHub organisation for materials, announcements and technical help.

Complete steps 1–5 **before your Week 1 seminar**. General course information is available on the [course website](https://lse-my472.github.io/).

> [!WARNING]
> **Use your five-digit LSE candidate number—not your nine-digit student ID.**
>
> You will need your candidate number throughout the course. You can find it in the Student LfY portal.

## 1. Create your course GitHub account

Create an **anonymised GitHub account** with a username in this exact format: `LSE-XXXXX-2627`. Replace `XXXXX` with your **five-digit candidate number**. Do not use your nine-digit student ID. The final four digits, `2627`, identify the 2026–27 academic year.

Then:

- Add your LSE email address to the account.
- Turn on two-factor authentication (2FA). You cannot join the course organisation without it.

You have completed this step when you have a GitHub account with: (1) a username in the correct format, (2) your LSE email connected to the account, and (3) 2FA enabled.

> [!TIP]
> We recommend applying for [GitHub Education](https://github.com/education) with your course GitHub account in order to access useful student benefits, like a free Pro account.

## 2. Complete the onboarding survey

Complete the [MY472 (AT2026) onboarding survey](https://forms.cloud.microsoft/e/ATkAWukuJu).

When you complete the survey, fill in your course GitHub username carefully. The teaching team will use it to invite you to the course organisation.

You have completed this step when you have submitted the survey.

## 3. Accept your invitation

The teaching team will review your survey response and send an invitation to your course GitHub account. This will not happen immediately.

When the invitation arrives, **accept it within 7 days**. You cannot access the course materials until you accept it.

You have completed this step when you can access private resources in the course GitHub organisation, such as <https://github.com/lse-my472/at26-community>.

## 4. Enable notifications

After joining the organisation, open the `at26-community` repository, available at <https://github.com/lse-my472/at26-community>.

Select **Watch → All Activity**. This is how you will receive important course announcements and updates.

You have completed this step when the repository’s watch setting shows **All Activity**.

## 5. Install the course software

Follow the [setup guide](setup.md) for macOS, Windows or Linux. It will guide you through installing:

- Python 3.14
- Quarto
- Positron, the editor used in this course
- Git

The guide also explains how to create the course’s Python environment and test it using the file [`setup-test.qmd`](setup-test.qmd).

You have completed this step when the test ends with **`ALL CHECKS PASSED`**.

You do not need Anaconda, conda or VS Code.

## Get help

If you have not received your organisation invitation:

1. Check that you submitted the correct GitHub username.
2. Check that 2FA is enabled on your GitHub account.
3. Contact the teaching team if both are correct, or if your invitation has expired.

For installation and computer problems, attend a drop-in help session with the course graduate teaching assistants:

- Wednesday 30 September, 16:00–17:00 (location to be confirmed).
- Wednesday 7 October, 16:00–17:00 (location to be confirmed).

Once you have joined the organisation, you can also open a **Tech help** issue in [`at26-community`](https://github.com/lse-my472/at26-community).
